Dookuture FAQ Agent

A live demo of an AI customer-service agent built with n8n and Google Gemini.

Open the chat button at the bottom right and try:

  • Do you open on Sundays?
  • How much is a senator set?
  • Do you sell bags? (it will ask for contact details)

Demo notes. Dookuture is a fictional brand. Please use fake names and numbers only. Messages are processed by Google Gemini's free tier. The chat is switched on only during demos, so if it doesn't reply, see the project repository for screenshots and the demo video.
